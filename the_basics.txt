the text styling 
the animation 
in the html code we write 
<p id="text">text</p>
in the style.css
we declare the animation first 
@keyframes textAnim { this is to change the color 
  from {
    color: red;
  }
  to {
    color: blue;
  }
}


@keyframes fade { this is to change the opacity
  0%   { opacity: 0; }
  100% { opacity: 1; }
}
@keyframes moveText {
  from { transform: translateY(-50px); } if we want to control the X

  to   { transform: translateY(20px); }  we should write translateX
}
            ↑  -Y (UP)    
            |
            |
            |       
- X (LEFT) ──●── +X (RIGHT)
            |
            |
            |
            ↓  +Y (DOWN)
 then we specify the text that we want to apply the animation at              
 .text {
  animation: textAnim 2s infinite;
  animation: fade 9s infinite;
   animation:  moveText 2s;
}
